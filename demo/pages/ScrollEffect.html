ScrollEffect

Demo showcasing configuration options for ScrollEffect.

Available Options

{
	threshold: 0.15, // Percentage of element that must be visible (0 to 1) for isInview
	rootMargin: "0px",
	startFromTop: false, // If true, progress starts from 0 when element top hits viewport top
	cssVar: "--scroll-progress", // The CSS variable to update (defaults to --scroll-progress)
}
