CSS Variable Parallax

Using parallaxCssVar: true allows you to drive any CSS property via the --parallax-scroll-progress variable.

Scaling & Rotation via CSS Var

Start From Top

With startFromTop: true, the parallax progress is calculated starting from when the top of the element hits the top of the viewport. (Useful for hero banners at the very top of the page).
