SplitText

Demo showcasing all configuration options for SplitText.

Available Options

{
	split: ["words"], // Can be any combination of lines, words, chars
	threshold: 0.1,
	rootMargin: "0px",
	once: true,
	wrapLines: false, // Physically wrap lines in a <span class="split-line">
}

Interactive Demo

Splitting Lines

This is a longer text that spans across multiple lines. We can apply bold words or italic words in-between to show that formatting is preserved. As you scroll down and this comes into view, the lines will animate in one by one. 

<p data-component="SplitText" class="split-lines-demo" data-options='{"split": ["lines"], "wrapLines": true}'>
  This is a longer text that spans across multiple lines. We can apply <strong>bold</strong> words
  or <em>italic</em> words in-between to show that formatting is preserved. As you scroll down and this comes
  into view, the lines will animate in one by one.
</p>

Splitting Words

Here is another paragraph demonstrating word splitting. It also spans multiple lines, but instead of the entire line fading in at once, each individual word pops in sequentially when this block reaches the viewport threshold.

</p>
