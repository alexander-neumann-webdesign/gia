OpenStreetMap

Demo showcasing all configuration options for OpenStreetMap.

Available Options

{
	locations: [], // Array of objects like: { lat: 51.505, lng: -0.09, title: "London" }
	centerCoords: null, // { lat: 51.505, lng: -0.09 }
	initialZoomLevel: 13,
	useAnimatedDot: false,
}
