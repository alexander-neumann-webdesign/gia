Marquee

Demo showcasing all configuration options for Marquee.

Available Options

{
	speed: 1, // Base scroll speed (pixels per frame)
	direction: "left", // 'left' or 'right'
	pauseOnHover: false,
	reactToScroll: false, // Whether to react to Lenis scroll events
	reactToMouse: false, // Whether to react to mouse position
}
