Toaster

Demo showcasing a Sonner-inspired Toast notification system using Gia's measure and mutate for smooth, layout-thrashing-free animations.

Available Options

{
	duration: 4000,
	gap: 14,
	maxVisible: 3,
	expandOnHover: true,
	swipeThreshold: 50,
	swipeVelocity: 0.11
}

Interactive Demo

<button onclick="gia.eventbus.emit('toast', { title: 'Default Toast', description: 'This is a default toast notification.' })">
        Add Default Toast
      </button>
      <button onclick="gia.eventbus.emit('toast', { title: 'Success', description: 'Your changes have been saved.', type: 'success' })">
        Add Success Toast
      </button>
      <button class="btn btn-error" onclick="gia.eventbus.emit('toast', { title: 'Error', description: 'Failed to save the document. Please try again.', type: 'error' })">Error Toast</button>
      <button class="btn btn-outline" onclick="gia.eventbus.emit('toast', { title: 'Long Description', description: 'This toast contains a lot of text to show how the container automatically adjusts its height dynamically during the measure phase!', duration: 8000 })">Long Description</button>
      <button class="btn btn-outline" onclick="gia.eventbus.emit('toast', { title: 'Dismissable', description: 'This one has a close button!', closeButton: true, duration: Infinity })">With Close Button</button>
