Gia Components Library

Select a component to view its demo and configuration options.

Navigation & Layout

  • Header A scroll-aware site header caching layout dimensions to apply CSS transforms via requestAnimationFrame without layout thrashing.
  • OffCanvasMenu A slide-out navigation menu demonstrating state-based class toggling, inert trapping for accessibility, and click-outside handling.

Accordions & Tabs

  • Accordion Semantic, accessible accordion utilizing <details>/<summary>. Manages state to auto-close sibling panels and syncs with the URL hash.
  • Tabs A modern tabbed interface powered by the View Transitions API for seamless cross-fading and sliding animations. Handles ARIA attributes and URL syncing automatically.

Overlays & Notifications

  • BottomSheet A highly interactive, touch-friendly bottom sheet (drawer) inspired by Vaul. It features responsive CSS variable-driven physics, a "mid-air catch" gesture engine, focus-trapping for WCAG accessibility, and full compatibility with Lenis smooth scrolling.
  • Modal An accessible dialog leveraging the native <dialog> element. Supports complex triggering, click-outside logic, and URL hash syncing.
  • Toaster A highly optimized, Sonner-inspired toast notification system featuring physics-based swipe-to-dismiss gestures, dynamic hover expansion, smooth height recalculation, and comprehensive WCAG accessibility.

Mouse & Interaction

  • CustomCursor A performant custom cursor replacement featuring frame-rate independent exponential smoothing for magnetic snapping and morphing.
  • Magnetic A physical "magnetic pull" effect for interactive elements that uses dual-layer parallax and recalculates spring physics dynamically.
  • Tooltip A robust tooltip component asynchronously importing the Floating UI library via require() for collision-aware positioning.

UI Elements

  • ClipboardCopy A utility component that copies text to the clipboard and provides temporary UI feedback based on state transitions.
  • CountUp An auto-parsing counting animation that triggers when scrolled into view, optimized for zero garbage collection during its loop.
  • ThemeToggle A dark/light mode toggle switch interacting with localStorage and mutating global document state.
  • QRCode A dynamic QR code generator that asynchronously loads dependencies to render customizable, reactive QR codes based on element attributes.

Media & Galleries

  • ImageComparison A responsive, fluid before/after comparison component utilizing CSS Grid stacking and a visually hidden range slider to dynamically adjust a clip-path mask via CSS variables.
  • ImageHolder A highly optimized image component providing smooth parallax, viewport entrance tracking, and dynamic sizes calculations.
  • LightboxGallery A fully-featured gallery demonstrating dynamic script loading by pulling in the PhotoSwipe library only when actually clicked.
  • Slider A swipeable, touch-friendly content slider demonstrating advanced pointer event handling and batched hardware-accelerated CSS transforms.
  • VideoHolder A highly optimized, lightweight background video player acting as a rich GIF replacement. Uses IntersectionObserver to pause when out of view to save CPU/GPU.
  • VideoPlayer A custom-styled video player featuring an animated expandable volume slider, scrubbable timeline, and IntersectionObserver logic that automatically pauses playback when out of view.

Scroll & Visual Effects

  • Marquee An infinite-scrolling marquee that automatically clones elements and handles continuous, sub-pixel perfect requestAnimationFrame updates.
  • Reveal A stagger-ready scroll-reveal component leveraging the globally shared Intersection Observer to handle hundreds of elements without memory leaks.
  • ScrollEffect A versatile scroll tracking component that maps viewport scroll progress to CSS variables, enabling complex animations like staggered grids and sticky stacked cards.
  • SplitText A specialized typography component that intelligently divides text into lines, words, and characters using the native Intl.Segmenter API.
  • TextFit A typography utility integrating the fitty library to seamlessly scale text to fit its container perfectly.

Forms & Selection

  • Form An AJAX-powered form component with built-in HTML5 validation handling, animated loading spinners, and state-driven success/error messaging.
  • MultiStepForm A robust multi-step form manager coordinating validation, step indicators, and smooth back/forward navigation.
  • MultipleSelect A wrapper for multiple-select-vanilla dynamically loading its dependencies and exposing standard value getters/setters.
  • RangeSlider A flexible range slider wrapping the noUiSlider library, implementing two-way data binding with native hidden inputs.
  • UploadField An accessible, drag-and-drop file upload field supporting multiple files, custom labels, and comprehensive keyboard interaction.

Complex Interactivity

  • FilterableList A filtering and sorting component synchronizing state with URL parameters and utilizing the modern View Transitions API.
  • FilterableListClassic A filtering and sorting component using native DOM manipulations without the View Transitions API, ideal for legacy browser support.
  • FilterableListGSAP A filtering and sorting component utilizing GSAP's Flip plugin for complex, hardware-accelerated grid reordering animations.
  • MapLibreMap An interactive WebGL map component loading maplibre-gl asynchronously. Features dynamic marker plotting from live Google Sheets CSV data, interactive popups, and custom map layers.
  • OpenStreetMap A Leaflet-based interactive map component asynchronously loading dependencies to plot markers dynamically.
  • MatterPhysicsBackground An interactive physics-based canvas utilizing Matter.js, including automatic pausing via IntersectionObserver to save CPU.
  • PongGame A complete, playable Pong game running a custom loop within requestAnimationFrame, demonstrating canvas drawing and input handling.
  • TodoApp A fully-featured todo application highlighting complex state arrays, local storage syncing, and accessible ARIA live regions.
